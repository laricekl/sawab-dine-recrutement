# Sawab Dine — Chasseur de têtes

Site vitrine personnalisé pour **Sawab Dine**, chasseur de têtes / recruteur au Québec.

## Structure
- `index.html` — page principale (10 sections)
- `styles.css` — design premium (marine + doré)
- `script.js` — interactions

## Sections
1. Accueil (double entrée entreprise / talent + chiffres clés)
2. À propos — Rencontrez Sawab Dine
3. Méthodologie (4 étapes)
4. Services & expertises sectorielles
5. Pour les entreprises (honoraires & garanties)
6. Pour les candidats (dépôt CV, Loi 25)
7. Mandats en cours
8. Insights (guide salarial)
9. Témoignages
10. Contact

## Notes
- Les éléments marqués **[À valider]** sont des placeholders à confirmer avec Sawab Dine
  (chiffres, témoignages, honoraires, garantie, mandats, photo professionnelle).
- Conformité à valider juridiquement : Loi 25 (protection des renseignements personnels),
  Loi 96 (version anglaise), WCAG 2.2.
- Formulaire de contact : démo front-end, à connecter à un backend.

## Développement local
Ouvrez simplement `index.html` dans un navigateur, ou servez le dossier avec :
```
python3 -m http.server 8000
```
